# Changelog

All notable changes to the CommuniMart Hyperlocal Community Marketplace are documented here.

## [1.0.0] - 2026-11-05
### Added
- Gated community resident unit/villa onboarding and verification flow.
- Door number privacy toggle (option to mask door until order acceptance).
- Hyperlocal catalog with Fixed Price, Giveaway (₹0), and Rental modes.
- Dual-role dashboards for Residents and Committee Admins.
- Handover logistics: Doorstep Delivery, Clubhouse/Security Drop-box, and Direct Flat Pickup.
- Dynamic UPI payment link generation with society order references.
- Real-time Socket.io direct resident-to-neighbor messaging.
- Community Notice Board for flash sales, requests, and society announcements.
- Dark mode Scandinavian design system with Emerald Teal aesthetic.
