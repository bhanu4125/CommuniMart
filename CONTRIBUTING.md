# Contributing to CommuniMart

We welcome contributions to make CommuniMart the best hyperlocal marketplace for gated residential communities!

## Development Workflow
1. Fork and clone the repository.
2. Install dependencies: `npm install`.
3. Set up MongoDB on `mongodb://localhost:27017/communimart`.
4. Seed demo data: `npm run seed`.
5. Run dev servers: `npm run dev`.

## Commit Message Guidelines
Please follow conventional commits:
- `feat:` for new user-facing features
- `fix:` for bug fixes
- `refactor:` for code restructuring
- `style:` for visual tweaks
- `docs:` for documentation updates
- `test:` for unit & integration tests
