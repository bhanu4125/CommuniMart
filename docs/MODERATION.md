# Managing Committee Moderation Guide

The CommuniMart Committee Admin Dashboard provides society executives with powers to maintain security and domestic tranquility.

## Admin Moderation Capabilities
1. **Resident Verification Roster**: Approve or reject new flat registrations based on physical society tenancy records.
2. **Catalog Moderation**: Remove prohibited items (firearms, hazardous chemicals, loud noise disturbances).
3. **Emergency Broadcasts**: Publish high-priority notices that trigger instant banners across all resident screens.
4. **Dispute Resolution**: Review transaction timestamps and chat history in the event of an unclaimed security box handover.
