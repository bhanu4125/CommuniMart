# Hyperlocal Return & Neighbor Inspection Policy

1. **Immediate Inspection**: Buyers should inspect pre-loved goods at the point of handover.
2. **Food Items**: Perishable and baked goods cannot be returned once handed over, unless spoiled at collection.
3. **Rental Equipment**: Tools or electronics must be checked for operational status upon pickup.
4. **Neighbor Mediation**: Committee Admin will intervene only if fraudulent misrepresentation occurs.
